# 규칙을 컴파일된 Rust 코드로 통일한다

YAML로 스코프·선언·참조·탐색 경계를 표현하면서 규칙 자체의 가독성이 나빠졌다. ADR-0001을 대체하여 모든 규칙을 Rust로 작성하고, YAML 규칙 엔진과 문법은 제거한다. AST 탐색과 바인딩 비교는 공통 Rust 라이브러리로 재사용하며 각 규칙은 이름 있는 함수, 타입 검사, 테스트를 활용한다.

규칙은 `src/rules/`의 `Rule` 구현이며 CLI와 함께 컴파일한다. CLI·hook은 안정적인 규칙 ID로 선택하고, Rust 소스 파일을 런타임 스크립트로 실행하지 않는다. YAML 규칙과 Rust 규칙을 병행하는 구조는 채택하지 않는다.

AST 후보 탐지와 AI 판단 기준은 해당 Rust 규칙에서 함께 관리한다. 규칙 코드를 수정하면 재빌드가 필요하다. 규칙 선택 및 모델 설정은 실행 시 읽으며 `.env` 수정에는 재빌드가 필요 없다. 기존 hook의 `ruleFiles`는 재설치 시 명시한 `ruleIds`로 전환한다.
